Chart.js showcase

These Chart.js examples visualize metrics and comparisons commonly found in specifications. Each chart uses semantic figure and canvas elements and takes its colors from the viewer theme.

About this page

When Chart.js is installed in the project, inline scripts in an HTML fragment can use the global Chart API directly.
