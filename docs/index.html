Designed for real specifications

文書のための、小さく強い道具。

Webアプリ一式ではなく、仕様書を読みやすくすることに集中。文書ごとのCSSやメニュー管理は不要です。

フォルダ構造と最初の見出しからメニューを自動構成。名前順・更新日順の切り替えにも対応します。

Quick start

いつものプロジェクトで、すぐ使える。

設計書を置くディレクトリに追加して、Viewerを起動するだけ。文書の変更は自動で反映されます。

  1. 1
    Install開発依存として追加
  2. 2
    WriteHTML fragment または Markdown を配置
  3. 3
    ViewローカルViewerを起動
Terminal 
# 1. install
$ npm install --save-dev spec-html

# 2. add your documents
$ mkdir -p specs

# 3. open the viewer
$ npx spec-html ./specs

✓ Viewer ready at http://127.0.0.1:4173

Local by design

信頼できる手元の文書に、閉じた道具。

Spec HTMLは公開Webサービスではありません。指定ディレクトリ外へのpath traversalとsymbolic link escapeを拒否し、dot fileを非公開にします。HTMLのinline scriptは実行されるため、信頼できないHTMLは開かないでください。
