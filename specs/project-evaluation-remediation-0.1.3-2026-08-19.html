プロジェクト評価課題の対処記録（0.1.3準備）

2026年8月19日付の2件のプロジェクト評価を統合し、0.1.3の準備として実施した対処と判断を記録する。結論として、release操作と検索機能を除く実装課題は対処済みである。package versionは、公開操作を行うまで0.1.2のまま維持する。

確定したscope
  • 文書検索は実装しない。規模別benchmarkだけを追加し、現在のnavigation性能を継続観測する。
  • 過去versionのtag、GitHub Release、release workflow、provenanceなどのrelease操作は、0.1.3公開後に行う。
  • GitHub repositoryのdescription、homepage、topics、非公開脆弱性報告はrelease操作ではないため、この対処に含める。

性能実測

release buildのCLIを実processとして起動し、生成したMarkdown文書集合で測定した。単位はmsで、navigation warmはtitle cacheが有効な2回目の値、reloadはfile更新からSSE通知までの値である。

2026年8月19日の規模別benchmark
文書数 起動 navigation cold navigation warm reload
50 158.1 36.1 2.0 64.7
500 172.5 61.3 4.8 63.2
5,000 158.9 348.0 33.5 65.4

50文書と500文書にはCI budgetを設定した。現在の結果から、0.1.3で検索indexを導入する性能上の必然性はない。
