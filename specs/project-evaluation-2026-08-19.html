強み

問題設定、防御、検証が揃っている

LLMが書く仕様を、共有CSSとnavigation付きのsemantic HTMLとして残す、という問題設定がはっきりしている。Markdown preview／convert／migrate は段階移行になっており、既存資産を壊さない。

Host allowlist、path traversal、symlink、dotfile、Markdown raw HTMLのliteral化、atomic create、migration lockまで、local toolとしては防御が厚い。脅威モデルを「trusted HTML」と明記している点も誠実である。

unit 414、Playwright（Chromium全件とFirefox／WebKit smoke）、pack後consumer、Node／Bun／3 OSのCIが揃う。TypeScriptはstrict、noUncheckedIndexedAccess、exactOptionalPropertyTypes。

減点の核

製品の穴より、公開手順とlocaleが目立つ

Viewerに検索がない。文書数が増えるとnavigationだけでは届かない。Markdownはpreviewできても lint／format／check の対象外で、混在rootでは品質ゲートがHTML側に偏る。

英語READMEを入口にしている一方、CLI helpとerrorは日本語固定である。英語利用者の第一印象を損なう。

npm 0.1.2は出ているが、git tagもGitHub Releaseもない。RELEASING.mdの「publish後にsigned tag」が未実施である。WindowsはNode 24.16+のfs.watch回帰を避けるため24.15.0固定。

観点ごとの根拠

上表の点数に対応する観察である。開いて詳細を読む。

製品価値 9.0

Spec HTMLは「LLMにWebアプリケーションを作らせる枠」ではなく、構造化HTML（と既存Markdown）のlocal viewerである。見出し、表、callout、details、図をMarkdownより自然に残せる一方、文書ごとのCSSとnavigationを不要にする。この非目標の書き方が、機能追加の境界を保っている。検索とfront matter解釈はv0.1の非目標として明示されている。

アーキテクチャ 8.5

cli、content、server、lint、format、fix、markdown、convert、migrate、browserに分かれる。previewとconvertが同じcompileMarkdownを使い、URL policyとheading IDの意味が揃う。Chart.jsとMermaidはoptional peerで、tarballへbundleしないことをpack testが検証する。

減点は規模である。src/browser/start.tsは約970行、src/migrate/planner.tsは約800行。navigation生成はrequestごとにMarkdownをcompileする。viewer bundleは119,128 bytesで、HTML-only利用でもMarkdown parserを含む。

コード品質 9.0

TypeScriptはstrict、noUncheckedIndexedAccess、exactOptionalPropertyTypes。ESLintはtype-checked。sourceにTODO／FIXMEはない。UTF-8のfatal decode、digest照合、atomic create／replace、symlink拒否が共通化されている。coverageの穴は成功経路中心のtest配分であり、実装品質そのものの問題ではない。

セキュリティ 9.0

既定は127.0.0.1。Hostはloopback名だけを許し、wildcard bindは--allowed-host必須。content routeはdot segmentとsymlink escapeを拒否する。Markdownはraw HTMLをliteral表示し、javascript:／data:／file:を落とす。Markdown由来のMermaidはstrict。変換は既存fileを上書きせず、migrationはlock、digest、rollback、lossyの明示opt-inを持つ。

trusted HTMLのinline scriptは実行する。iframeにsandboxは無い。これは文書化された非目標であり、untrusted入力を安全にする製品ではない。fixerがscritpを直すとscriptが有効になる点もREADMEが警告する。

テスト 9.0

Node test 414、Playwright、pack後の別project install、coverage閾値80%、CI matrixが揃う。0.1.xのCLIとしては厚い。browserの11 filesはcoverageから除外され、Firefox／WebKitはsmokeのみ。Windows CIはNode 24.16+のfs.watch回帰を避けるため24.15.0へピン留めしている。

ドキュメント、UX、リリース、互換性、コミュニティ

英日README、authoring guide、CONTRIBUTING、RELEASING、CHANGELOG、examples、AGENTS.md用のコピー可能指示がある。ViewerはOSテーマ、印刷、keyboard、mobile navigation、source dialog、文書lint（alt、caption、見出し順、ARIA）を持つ。

信頼できるlocal環境で、LLMが書いた仕様・設計・調査を人間が読む用途には十分強い。公開Web、untrusted HTML、大規模ナレッジの検索基盤としては、このversionの対象外である。コミュニティ5点は作成2日目としては自然で、総合を大きく押し下げないよう重み4に抑えた。
