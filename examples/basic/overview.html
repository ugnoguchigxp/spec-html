Overview

Spec HTML displays AI-generated specifications as regular HTML fragments.

Requirements

  • Write semantic HTML.
  • Use one h1 as the navigation title.
  • Review the document structure.
Note

The default styles follow the operating system's light or dark appearance.

Warning

Only open trusted HTML because inline scripts are executed.

Semantic elements

Use meaningful elements and press Tab to verify focus order.

Fragment
HTML content beginning with an element such as article.
Navigation
Links derived from the content directory.
Semantic HTML keeps the document useful with or without the Viewer.
